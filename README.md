# Kickstarter Project Success Prediction

UE24CS352A Machine Learning Mini-Project, Problem #56. Predicts whether a Kickstarter campaign will succeed
from launch-time information (goal, duration, category, location, dates, blurb text). Approach follows the
CS229 report *Crowdfunding: Predicting Kickstarter Project Success*.

**Team:** Aaditya Vijaywargi PES1UG24AM003 and Amruta Sai PES1UG24AM035

## Important: the dataset is synthetic
`kickstarter_success_prediction_dataset.csv` (20,000 rows) is generated by `generate_dataset.py` (seed 42).
It is **not** scraped Kickstarter data. Patterns are modelled on public Kickstarter trends, so results describe
this data and are not comparable with real-data results. To use real data, replace the CSV with one using the
same columns.

## Setup and run

```bash
python -m venv venv && source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook Kickstarter_Success_Prediction.ipynb # Run All (keep the CSV in the same folder)
```
On Google Colab, upload the CSV when prompted. The grid search (120 fits) takes roughly 10 to 20 minutes.
To regenerate the data: `python generate_dataset.py`.

## Method
1. Metadata: median imputation and scaling (numeric), one-hot encoding (categorical)
2. Text: TF-IDF and Multinomial Naive Bayes; the training-set probability uses 5-fold out-of-fold predictions to avoid leakage
3. LDA (10 topics) topic features
4. Seven classifiers compared; Gradient Boosting tuned with 5-fold GridSearchCV

## Results (6,000 held-out projects; majority baseline 54.8%)
| Model | Accuracy | ROC-AUC |
|---|---|---|
| Gradient Boosting | 0.715 | 0.790 |
| Random Forest | 0.696 | 0.771 |
| Neural Network | 0.691 | 0.763 |
| L1 Logistic | 0.691 | 0.759 |
